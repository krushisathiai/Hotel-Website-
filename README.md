# Hotel-Website-

**DineFlow - Indian Restaurant Management System (Frontend)**

A modern, responsive React + Vite web application for Indian restaurant operations.

## Features
- **Role-Based Access Control:**
  - 👑 **Owner:** Real-time business analytics, sales metrics, floor status, and settings.
  - 🍽️ **Waiter (Floor Staff):** Interactive POS order taker with table selection and kitchen dispatch.
  - 👨‍🍳 **Kitchen Display System (KDS):** Live preparation board with "Start Cooking" and "Mark Prepared / Ready".
  - 💼 **Billing & Cashier (Manager):** Live bill settlement, discount application, UPI/Card/Cash support, and printable thermal GST receipts.
- **Table & Floor Management:** Real-time table occupancy tracking (`🟢 Available` / `🔴 Occupied`).
- **Menu & Category Catalog:** Veg/Non-veg tags, pricing in Indian Rupees (₹), and instant item toggling.
- **Loading Indicators:** Spinners on all action buttons.

## Tech Stack
- React 18
- Vite
- Lucide React (Icons)
- Recharts (Visual Analytics)
- Axios
